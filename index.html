    Module 4 • Free Static Hosting & Deployment

    Deploy for $0 on GitHub Pages or Cloudflare Pages

    This entire application is engineered as a zero-backend, subpath-safe static application (index.html) with zero external API keys—making it 100% compatible with GitHub Pages and Cloudflare Pages.

    Option 1 (Recommended): GitHub Pages (10-Step Beginner Guide)

    1. Create or sign in to your free GitHub account.
    2. Click New repository, name it data-career-bootcamp, set visibility to Public, and click Create.
    3. Upload index.html (and optional README.md, research_dataset.json) to the root of the repository.
    4. Verify that the entry file is named exactly index.html (lowercase) at the top-level directory.
    5. Open your repository's top tab bar and click Settings.
    6. In the left sidebar under "Code and automation", click Pages.
    7. Under Build and deployment → Source, select Deploy from a branch.
    8. Select branch main (or master) and folder / (root), then click Save.
    9. Wait 60–90 seconds and refresh the Pages settings screen to see your live URL: https://<your-username>.github.io/data-career-bootcamp/.
    10. Updating the site: Whenever you edit index.html and commit/push to main, GitHub Actions automatically redeploys the site in ~1 minute.

    Official Guide: GitHub Pages Official Documentation (Note: GitHub Pages is for static websites, not a backend database server).

    Option 2: Cloudflare Pages Connected to GitHub

    1. Push your project repository (with top-level index.html) to GitHub.
    2. Log in to the free Cloudflare Dashboard and navigate to Workers & Pages → Create application → Pages → Connect to Git.
    3. Authorize Cloudflare and select your data-career-bootcamp repository.
    4. Leave Build command blank (no build step required!) and set Build output directory to /.
    5. Click Save and Deploy. Your site will be live on https://<project>.pages.dev, and every future git push triggers an automatic global CDN deployment.
