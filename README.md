# 60-Day AI-Researched Data Engineering, Analytics & Microsoft Fabric Bootcamp

An interactive, research-driven, zero-API-key learning platform and career workspace covering **Data Engineering**, **Data Analytics**, **SQL**, **Python**, **PySpark**, **Power BI (DAX & Star Schema)**, **Azure Data Services**, and **Microsoft Fabric (DP-700, DP-600, PL-300)**.

## Key Architecture & Features
1. **Strict No-External-AI-API Architecture**: Runs 100% client-side as a static single-page web application (`index.html`). No Gemini, OpenAI, or paid model API keys required.
2. **Empirical Job-Market Research Dataset (`research_dataset.json`)**: Built from 34 verified India (Noida, Gurugram, Delhi NCR, Bengaluru, Hyderabad, Pune, Chennai, Mumbai) and Remote job descriptions + 28 verified Hindi/Hinglish and English learning resources.
3. **Dynamic DAG Curriculum Generator**: Topologically sorts 60 skill nodes based on prerequisite relationships, empirical job-market skill frequencies, target role weights, starting baseline, and daily quiz/confidence assessments.
4. **60 Complete Daily Learning Studios**: Every day (Day 1 to Day 60) includes Daily Mission, First-Principles Deep Conceptual Teaching, Worked Production Code, Bilingual Resources, 5-Tier Hands-On Lab with hidden solutions, 3-Question Revision Quiz, Tiered Interview Prep, Truthful English/Hinglish LinkedIn Post Generator, Configurable Checklist, and Reflection Journal.
5. **6 Progressive Portfolio Projects & Microsoft Fabric Capstone**: Each includes a 100% Free Local Execution alternative (Python + DuckDB/SQLite + PySpark + Power BI Desktop `.pbip`) alongside cloud deployment.
6. **Module 1 — Project Interview Preparation Center**: Project-specific English/Hinglish interview kits, Transparent Rubric Mock Coach, Truthful STAR Story Builder, and 10 System Design Architecture Labs.
7. **Module 2 — Professional ATS-Friendly Resume Builder**: 6 role-targeted generators, 5 ATS layouts, Project-to-Resume truthful bullet approval, 10-point quality checklist, Print/PDF export, and `.doc` export.
8. **Module 3 — Evidence-Based Readiness Dashboard**: Separates *Knowledge Learned* from *Skills Demonstrated* and generates a dynamic Weekly Action Plan.
9. **Module 4 & 5 — Free Static Hosting & Local Portability**: Ready for 1-click deployment on **GitHub Pages** or **Cloudflare Pages** with full JSON progress backup/restore and a Legacy HTML Bootcamp Importer.
